Riverwood Drive Indexer

Riverwood Drive Indexer is an internal tool used by the riverwood team to scan and index Google Drive files (research reports and recordings) belonging to a single Google account, so the team's Claude Code assistant can search and answer questions about them.

This app requests read-only access to a single, explicitly user-selected Google Drive folder (via the Google Picker) using the drive.file scope. It does not access any other files in the user's Drive.

This is an internal tool for a single organization, not distributed publicly.
